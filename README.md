# Renato Brito

AI Builder: construo agentes e automações que rodam em produção, com guardrails e sem falhar em silêncio.

**O que eu faço**
- Agentes com Claude Code headless (`claude -p`) agendados, com fila, retomada e alerta de falha
- Guardrails para agentes: hooks de permissão, aprovação humana e trilha de auditoria
- Servidores MCP com menor privilégio
- Automação web com Playwright (Node/TypeScript) em lote seguro: dry-run, checkpoint, rollback
- Extensões Chrome MV3 com LLM

**Stack:** TypeScript · Node · Python · Playwright · Claude Code / MCP · Chrome Extensions MV3

**Projetos em destaque**
- [claude-code-policy-guard](https://github.com/reanto-afk/claude-code-policy-guard): guardrails e aprovação humana para agentes do Claude Code
- [claude-headless-runner](https://github.com/reanto-afk/claude-headless-runner): rotinas de IA agendadas que não falham em silêncio
- [playwright-safe-batch](https://github.com/reanto-afk/playwright-safe-batch): automação web em massa com dry-run, checkpoint e rollback
